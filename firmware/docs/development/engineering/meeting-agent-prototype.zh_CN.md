# 会议录音 Agent 原型

单设备原型通过经认证的 Security 2 BLE 会话传输 Wi-Fi、服务端凭据、CA 和初始时间。电脑先验证配置的服务端 TLS 证书，并将 HTTPS Date 与本机时间比较，再发送配置。原型固件可以自动进入配网并接受时间，无需按键。此流程不会格式化录音存储。

`tools/meeting_provision.py CONFIG --watch` 持续查找唯一配网服务、完成认证和配置，并在设备重启后继续等待。运行需要已激活的 ESP-IDF 5.5.3 环境、BLE 依赖、`MEETING_TEST_PAIRING_CODE` 和 `MEETING_TEST_AUTO_CONFIRM=1`。凭据通过受保护的环境提供，配置文件放在仓库外并限制为文件所有者可读写；使用 Ctrl-C 停止。发现多个匹配设备时不会自动选择。BLE 持久化确认只表示设备确认了配置，Wi-Fi 连接和上传须另行检查。

监听器区分“未找到唯一匹配设备”和“配网未完成”，同类故障重复时不刷屏，也不输出异常详情或凭据。名称不匹配时不会发送配置；应先确认目标，而不是强行覆盖名称。

这是单设备测试机制，不是正式产品的首次使用方案：固定配对值嵌入该设备的测试固件，设备没有启用安全启动和 Flash 加密，能够读取或修改固件、Flash 的人不在原型保护范围内。正式的 Agent 配网、设备身份、可信时间和凭据生命周期仍需设计和验证。设备尚不能在重启后独立重建可信时间，因此仍需运行监听器；监听器运行并不代表上传已完成。
