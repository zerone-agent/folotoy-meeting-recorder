# 固件基线

从 ai-passport-soundcore 固定提交 `569b863c4f5444bf5f5c914ceb2ba6bec2bf94ad` 的归档复制，保留原项目许可证与说明；构建目录和下载依赖不纳入。

录音分区挂载失败时不会自动格式化，以免损坏可恢复录音。会议服务自动上传、Wi-Fi 配网及确认后清理尚未接通，禁止将其视为已完成的会议录音卡。空白分区需要明确初始化流程，不能因挂载失败自动擦除。

会议卡删除和凭据撤销状态机尚未实现，旧第三方协议的远端删除与恢复出厂命令暂时返回失败，避免未经设备确认擦除录音或重置身份；这会改变参考固件兼容行为。这不能替代后续手动删除及撤销待办功能。
