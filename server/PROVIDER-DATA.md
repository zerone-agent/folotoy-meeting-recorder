# StepFun 数据处理边界

核查时间：2026-10-30。当前服务把录音发送给 StepFun ASR，将转写文本发送给 StepFun 纪要模型；本服务的删除只操作本地数据库，不会调用供应商删除接口。

StepFun 开放平台[隐私政策](https://platform.stepfun.com/legal/privacy-policy.html)（页面列明 2026-04-23 生效）说明，使用模型和 API 能力时会收集用户主动输入的信息，包括语音、录音及输出信息；个人信息保留期限以提供服务所需为原则，删除或匿名化存在法定留存等例外。政策没有在所查部分给出 ASR 音频或纪要请求的具体留存天数，也没有证明本服务的删除操作会同步删除供应商副本。

[开放平台用户协议](https://platform.stepfun.com/legal/user-agreement.html)描述了为提供、诊断和改进服务处理相关数据的条款。此处记录的是公开平台条款，不能推断当前 Step Plan 账户、具体模型或另行签署的企业协议是否有不同约定。

部署前需要向供应商确认当前账户和模型的音频、转写、模型输出、日志及备份的留存期限和删除途径，以及是否用于模型改进；依据确认结果设置业务说明与备份策略。当前不能承诺供应商侧即时删除，也不能假设其零留存。供应商政策可能更新，应在部署和续约时重新核对。
