# SCR1 Automatic Upload Implementation Plan

**Goal:** 实现可恢复的离线录音、配网和 Wi-Fi 自动上传，服务端确认前不删除设备副本。

**Architecture:** 固件按录音、存储、配置与上传任务分离；基于持久化状态与稳定 SCR1 脱敏快照，通过 HTTPS 分块提交服务。服务端现有清单协议为权威确认。

**Tech Stack:** ESP32-C3、ESP-IDF 5.5.3、LittleFS、NVS、HTTPS、Node.js 服务端。

**Spec:** docs/superpowers/specs/2026-11-02-scr1-auto-upload-design.md

## 全局约束

保留用户设备数据；不自动格式化未知分区；录音优先；不上传 SCR1 内第三方文件密钥；不跳过 TLS、证书或时间验证；设备刷写需要另行确认恢复路径。测试和构建不代表实机验收。

## 工作项

- [ ] 固定固件来源与依赖，按项目指南验证主机和固件构建；确保空白分区与损坏分区不被自动格式化。
- [ ] 加入可单元测试的 SCR1 字节流脱敏：偏移 24–71 固定清零，其他字节原样；重复读取、块跨界、服务端验证、哈希一致、旧密钥不泄露均测试。
- [ ] 设计并实现可检测撕裂的持久录音状态、随机会议 ID、结束原因、快照清单、确认和删除墓碑；故障注入每个提交点。
- [ ] 完整分区擦除态检测和用户按键确认；未知/损坏状态禁止格式化；验证格式化中断和首次初始化。
- [ ] 实现认证加密 BLE 配置和电脑工具，完成设备凭据、Wi-Fi STA、信任锚、可信时间及离线撤销待办；测试重放、错误时间、重启与重配。
- [ ] 实现分块查询、传输、修复、幂等提交及确认逐项校验，控制 TLS 内存，确保录音抢占上传和断电续传；主机模拟服务测试故障交错。
- [ ] 实现手动删除及取消待办、确认后清理、空间与异常显示；测试上传确认与删除、反复重启及存储失败。
- [ ] 构建 ESP-IDF 5.5.3 固件并通过主机测试；核查固件大小、分区余量与 TLS 堆峰值。设备连接及刷写前确认恢复方式，再测试 30 分钟、断网、断电、确认丢失和空间恢复。
