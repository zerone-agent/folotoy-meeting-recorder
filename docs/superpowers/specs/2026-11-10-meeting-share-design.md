# 会议纪要网页分享

## 目标与范围

管理员可以为单场已生成纪要的会议创建临时链接，接收者无需管理员令牌即可阅读该会议的最新纪要。分享设置中纪要始终选中且不可更改，逐字稿可选、默认不选；有效时长可填写，默认 7 天。分享页保留自动生成内容需要人工复核的提示。不实现订阅推送、音频分享、分享管理列表或人工编辑。

## 方案

采用服务端保存分享记录：每次创建生成独立的高随机度凭证，记录其哈希、会议、逐字稿权限和过期时间；访问时检查记录并读取当前会议结果。备选的自包含签名链接无需记录，但单独撤销困难，故未选用。

## 交互

会议详情有纪要时显示“分享”。弹窗显示必选且禁用的“会议纪要”、默认未选的“逐字稿”和以天为单位的有效时长，默认 7，允许 1–365 的整数。创建成功后在弹窗展示可复制的完整链接及到期时间；失败时保留设置并提示错误。可关闭弹窗，键盘可操作并具有明确的标签与焦点处理。链接基于管理员当前访问页面的 origin 和部署路径生成；管理员须使用接收者可访问的地址，localhost 链接不能被远程访问。

分享页无需登录，展示纪要以及必需的人工复核和录音不完整提示；仅当勾选逐字稿时展示逐字稿。内容只读，以文本安全渲染；不返回音频、其他会议、管理员数据或未授权逐字稿，也不返回包含原文引用的结构化证据；现有 Markdown 纪要渲染器不输出证据字段。有效期以服务端创建时间计算，过期时显示链接失效。链接持有者均可访问，页面须提示管理员妥善分享链接；复制失败时仍可手动复制。

## 数据和行为

- 管理员认证的创建接口校验会议当前存在且有纪要、时长和逐字稿选项。服务端生成至少 256 位随机凭证，只保存 SHA-256 哈希；创建响应仅返回一次原始凭证和到期时间。
- 使用 URL fragment 携带凭证，分享页以请求头发送凭证获取数据，避免凭证进入服务器访问日志、Referer 和常规 URL 请求；设置禁止缓存、禁止来源泄露和严格 CSP，不加载外部资源。无效、过期或已删除会议统一返回不可访问，不暴露会议是否存在。
- 每次访问读取当前纪要及其匹配的当前逐字稿。重新转写期间现有实现会清除当前结果，此时页面提示结果暂不可用，完成后同一链接展示新结果；不回退到旧版本或混合版本。到期不会延长。
- 删除清理及保留期删除清除对应分享记录；定期清理过期记录。服务重启后未过期链接仍有效。
- 不提供单独撤销功能；创建新链接不会使旧链接失效。当前部署的 HTTPS、反向代理、访问日志和速率限制仍需按服务现有安全要求配置。
- 有效期依赖服务端系统时钟；运维应保持时钟准确，时钟回拨可能延长链接的实际有效时间。

### 并发与访问边界

分享数据接口在一次 SQLite 读事务的同一快照中，以单次捕获的服务端时间检查凭证哈希、有效期和会议状态，并读取当前纪要、逐字稿及其版本关联。仅在状态允许且当前纪要与逐字稿属于同一已提交版本时返回授权投影；结果缺失或版本无法证明匹配时返回暂不可用，不返回部分内容。创建分享对会议存在、纪要可用的检查和记录插入也必须原子完成，防止并发删除后创建记录。

读取以建立数据库快照为线性化点：若删除进入 `deleting` 的事务或重新转写事务先于快照提交，读取必须观察新状态；若读取先建立快照，即使删除随后提交，已经开始的请求仍可能返回该快照中的内容。已发送或在途的数据无法撤回；删除提交后的新读取不得访问。重新转写及结果发布遵守同样的先后规则，不能混合两个版本。分享过期以该次读取捕获的服务端时间判定，过期后开始的新读取不得成功。

匿名例外仅包括固定的分享页面 GET 和只读分享数据接口；二者在现有全局 bearer 认证中间件之前精确注册，数据接口仍必须校验分享凭证。创建及其他业务路由仍经过原有管理员或设备认证；不使用宽泛的路径前缀或方法通配放行。错误响应也设置无缓存、无来源泄露等适当安全头。

### 恢复

恢复仍须按现有流程停止服务，验证最新安全数据库的完整性、外键及实例身份，并在同一安全数据库快照内读取分享状态。恢复目标中先清空备份携带的所有分享记录，再以最新安全数据库为权威替换：仅复制快照中未过期、字段合法、关联最新状态中未删除会议且在恢复目标中有效的记录。备份后创建的有效链接因此保留；备份后已删除、清理或过期的链接不会复活。会议结果仍遵守现有恢复一致性检查，不能用分享记录绕过检查。

现有历史库没有可证明其版本的标记，因此不尝试根据缺表推断它是合法旧库。分享功能首次迁移在同一事务中创建分享表和持久化标记；正常启动及恢复时校验标记值、表结构和记录。两者均不存在时，恢复允许继续，但将目标中的所有分享清空，并明确报告“分享状态无法验证，所有链接已失效”；不得从备份补回。这条规则同样适用于被降级或丢失了两者的安全库，安全性依赖于全部失效，而非断言它确为旧库。

仅有标记或仅有表、标记值不受支持、表结构或记录无效，均视为状态不一致，恢复失败并移除未完成输出。若安全数据库缺失、身份或完整性无法验证，也必须恢复失败；恢复过程中校验失败须回滚，不得产生可用的部分结果。正常启动时，仅对标记和表均缺失的库执行原子迁移，创建空分享表；一旦启用分享，回退到不支持该功能的旧服务并重新写入数据库，可能丢失可验证的分享状态。重新升级或恢复时不得从备份复活链接；运维需避免降级，并在状态不可证明时重新创建链接。标记和表同时被回滚至一致的历史状态，仅靠同一个数据库无法检测，因此最新安全数据库仍须由运维确保为切换前可信的最新副本；不能把该标记当作防篡改或防回滚证明。

## 验证

测试创建权限、参数边界、随机凭证与哈希存储、过期边界、权限隔离、最新版本、删除和保留期、重启、无法泄漏凭证及安全响应头。以受控事务交错测试读取快照先于及晚于删除、重新转写和结果提交，验证不会混合版本，并验证删除提交后的新读取失败；测试创建与删除竞争。恢复测试覆盖备份后新增及删除分享、过期分享、删除会议、标记和表同时缺失时全部失效、标记和表单独缺失、未知标记、旧版迁移、降级后重新升级及恢复、无效记录、身份不符和完整性失败；同时验证无法检测同库一致回滚的限制。测试匿名例外的精确路径与方法，验证其他路由仍须认证。浏览器检查弹窗默认值、键盘操作、复制和分享页的正常、不可用及过期状态，并运行现有服务测试。使用合成数据，不进行真实会议外发。
