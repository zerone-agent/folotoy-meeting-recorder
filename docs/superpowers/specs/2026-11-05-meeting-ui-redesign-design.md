# 会议录音工作台界面改版

## 目标与约束

参考 Agent Hub 的暖灰背景、陶土橙主色和清晰的内容层次，改善会议查找、处理状态和纪要阅读。继续使用现有服务生成的轻量页面，不引入前端构建链或改变部署方式、API、认证及七天令牌缓存。会议内容仍以安全文本方式插入，保留 CSP；不向浏览器引入外部资源。

## 方案

- **选定：现有单页重做。** 保持服务端生成 HTML 与原生浏览器代码，重构布局和交互，部署无新增步骤。
- **备选：引入 Agent Hub 的前端框架。** 组件复用和长期扩展较方便，但需要额外构建、依赖和部署维护；目前功能规模不需要这一成本。

## 页面与交互

- 未登录时提供清晰的管理员令牌入口，说明本浏览器缓存七天；可按回车提交，认证失败时保留明确提示。登录后提供刷新列表、退出登录和清除本地令牌入口，不影响服务端凭据。
- 桌面端使用左侧会议列表、右侧会议详情。列表保持服务端分页顺序，以录音时间及处理状态为主要显示信息，时间不可用时明确标注；会议 ID 用于辅助识别，不能伪造时间。状态区分处理中、完成、失败及不完整录音。保留分页加载，提供针对已加载会议的搜索和状态筛选，并明确其范围。
- 详情优先展示会议纪要，提供转录视图切换及录音下载；在可用时提供纪要下载；仅在服务端确认已提交且音频完整性验证通过时启用音频下载，其他情况说明不可用。保留处理进度、失败原因及重试、删除确认、未完成删除清理提示。处理中和空数据提供明确状态，结果需人工复核及音频不完整的提示始终可见。
- 设备上报的时间是否可信须如实显示，trusted 仅表述为设备标记可信；无法校准或不可信时不得作为可靠会议时间。删除仅删除服务端会议及其相关数据，确认前清楚提示后果。
- 退出、令牌失效、刷新、切换会议或删除时，使相应在途请求的晚到结果失效，避免敏感详情或已删除内容重新出现；删除失败时保留可操作状态。删除清理列表存在更多页时明确提示。重试可用性按实际处理阶段和服务端响应判定。
- 手机端列表和详情以单栏呈现，进入详情后可返回列表。键盘可操作、焦点清晰、交互控件有可访问名称；加载、空列表、无搜索结果和网络错误均有反馈。保持文字对比度并尊重减少动画偏好。

## 验证

- 运行现有服务端测试，重点覆盖七天缓存、过期、认证失败、分页、会议详情、删除和重试；补充请求乱序、退出及删除后的晚到响应、下载不可用、分页筛选和 CSP 的针对性检查。
- 在浏览器用测试数据核对桌面和窄屏：登录、刷新恢复、列表筛选、详情切换、各种状态、下载与删除确认；确保不会对真实会议执行删除或重试。
- 不以浏览器界面测试声称设备上传或模型内容准确性通过；不修改线上配置或发布，除非用户后续要求。
