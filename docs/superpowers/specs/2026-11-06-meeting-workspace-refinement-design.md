# 会议工作台细节调整

## 目标与约束

保持现有轻量页面和部署方式，调整会议详情、列表与视觉细节；保留录音、转录、纪要、编辑及删除的现有安全语义。

## 方案

- 会议详情保留标签切换：左侧标签为会议转录，右侧标签为 Markdown 纪要；默认显示纪要，保留下载和编辑操作。每段仅显示紧贴数字的 `s`，不显示“VAD 估计”；页面和下载稿在转录内容开头统一注明时间范围为估算，识别差异提示不变。
- 列表分页提供 10、20、50、100 条，默认 20，上一页、下一页及当前页状态明确；搜索和状态筛选由服务端覆盖全部会议。旧接口调用保持兼容。列表变化、删除、筛选及更改每页数量时处理空页与分页状态，响应并发时避免旧请求覆盖新结果。
- 完成纪要后列表和详情使用纪要中模型生成的会议主题作为标题；主题不可用时保留时间标题。无需额外模型请求；历史纪要同样适用，录音时间仍在详情中显示，模型生成标题不作为可信事实。
- 参考 Router Dashboard 的 Zerone 标志、细线图标与自定义选择器；状态和每页数量选择器统一，包括选中态、键盘操作、焦点和点击外部关闭。

## 比较与选择

浏览器加载全部会议再分页实现较简单，但数量增长后加载和过滤开销增加。选择服务端查询分页，以支持全量搜索和筛选，同时避免每次加载全部会议。

## 验证

自动测试覆盖分页边界、总数、搜索和筛选、兼容性与标题回退；浏览器验证桌面和移动端标签切换、两个选择器键盘与鼠标操作、分页、纪要编辑保存刷新及转录下载。只使用测试数据，不修改用户已有会议。
